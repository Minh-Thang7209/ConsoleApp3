1. Що таке CLR?
Відповідь: CLR (Common Language Runtime) — середовище виконання .NET, яке виконує керований код і надає служби керування пам’яттю, винятками та типами.

2. Що таке sealed клас?
Відповідь: sealed клас — клас, від якого не можна успадковувати інші класи.

3. Яка різниця між ref та out параметрами?
Відповідь: ref потребує попередньої ініціалізації змінної. out не потребує ініціалізації до виклику, але метод повинен присвоїти йому значення.

4. Що таке readonly поле?
Відповідь: readonly поле можна ініціалізувати під час оголошення або в конструкторі; після цього його значення не можна змінювати.

5. Масив — це value type чи reference type?
Відповідь: Масив у C# є reference type, навіть якщо його елементи є value types.

6. Що таке поліморфізм?
Відповідь: Поліморфізм — можливість працювати з об’єктами різних типів через спільний базовий тип або інтерфейс, при цьому кожен тип може мати власну реалізацію поведінки.

7. Що таке конструктор?
Відповідь: Конструктор — спеціальний метод класу, який викликається під час створення об’єкта та виконує його початкову ініціалізацію.

8. Що таке властивість?
Відповідь: Властивість — член класу, який надає контрольований доступ до даних за допомогою accessors, наприклад get і set.

9. Що таке пакування (boxing) і розпакування (unboxing)?
Відповідь: Boxing — перетворення value type на object або сумісний reference type. Unboxing — явне вилучення value type із object.

10. Що таке метод класу?
Відповідь: Метод класу — функція, оголошена всередині класу, яка описує певну дію або поведінку цього класу.
